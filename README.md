
# OASIS Dino Run

## About the project
A 2D dinosaur runner game inspired by
the Google Chrome Dinosaur Game.

## Programming language
C++

## Library
raylib

## Team members
- Member 1: Othman
- Member 2: Alaoma
- Member 3: Sifrina
- Member 4: Ikenna

## Features
- Dinosaur jumping
- Moving obstacles
- Collision detection
- Score system
- Game over screen
- Restart option

## How to play
- Press SPACE to jump.
- Avoid the obstacles.
- Try to achieve the highest score.
